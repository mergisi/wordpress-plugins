## Why These Plugins?

Every plugin here follows the same principles:

- **No bloat** — does one thing, does it well
- **No external API dependencies** (where possible)
- **No subscriptions required** for the core functionality
- **GPL-2.0+ licensed** — you own the code

## Installation

Each plugin has its own repo with full installation instructions. General steps:

1. Download the latest `.zip` from the plugin's **Releases** tab
2. Go to **WordPress Admin → Plugins → Add New → Upload Plugin**
3. Upload the ZIP and click **Activate**
